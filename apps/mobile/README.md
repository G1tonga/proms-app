# PROMs App

Patient Recovery Outcome Measures: a React Native (Expo) app for orthopedic patients, with an Express and PostgreSQL backend.

## Structure

- `apps/mobile`: Expo app (patient, clinician, admin and researcher screens)
- `apps/api`: Express API
- `docs`: architecture and reference documents

## Run the mobile app

    cd apps/mobile
    npm install
    npx expo start
